# Specification

## Summary
**Goal:** Limit the interest calculator to a maximum of 1 year by replacing the years input with a days input field.

**Planned changes:**
- Replace years input with days input (1-365 range)
- Update calculation logic to convert days to fraction of year (days/365)
- Display days value in calculation results
- Update validation to enforce 1-365 days range

**User-visible outcome:** Users can calculate interest for periods up to 365 days using a days input field instead of years, with results showing the exact number of days used in the calculation.
